# Modules ES6

Cette directory contient tous les modules ES6 réutilisables pour l'application BSG.

## Modules disponibles

- **SupabaseManager.js** : Gère toutes les interactions Supabase
- **AuthManager.js** : Gère l'authentification
- **MissionEngine.js** : Logique métier des missions imbriquées
- **LocationService.js** : Géolocalisation avec Leaflet/OpenStreetMap
- **NotificationHandler.js** : Gestion des notifications browser push
- **WebhookManager.js** : Communication sécurisée avec n8n
