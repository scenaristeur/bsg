# Composants Vue 2

Cette directory contient tous les composants Vue 2 pour l'application BSG.

## Composants principaux

- **Auth.vue** : Connexion multi-méthodes
- **Dashboard.vue** : Vue d'ensemble missions
- **MissionMap.vue** : Carte interactive Leaflet
- **MissionDetail.vue** : Détail + progression
- **Profile.vue** : Compétences, historique
- **Notifications.vue** : Centre de notifications
- **SocialHub.vue** : Chat, échanges
