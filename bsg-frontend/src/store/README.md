# Vuex Store

Cette directory contient tous les modules Vuex pour la gestion d'état de l'application BSG.

## Modules disponibles

- **auth.js** : Gestion de la session et des permissions utilisateur
- **missions.js** : Gestion des missions actives et de leur progression
- **map.js** : État de la carte et des POIs visibles
- **notifications.js** : Gestion des notifications en attente
- **social.js** : Gestion des interactions sociales entre joueurs
